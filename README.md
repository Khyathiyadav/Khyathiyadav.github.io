# 🌐 Khyathi Yadav - Personal Portfolio Website

This is a personal **e-portfolio website** for showcasing my skills, projects, and achievements.  
The website is built with **HTML, CSS, and JavaScript** (for animations, scroll effects, etc.).

---

## 🚀 Features

- Clean, modern, and professional design  
- Single-page layout with smooth scrolling  
- Sections included:  
  - Hero / Header with profile intro  
  - About Me  
  - Skills  
  - Projects  
  - Resume  
  - Contact  

---

## 🛠️ Technologies Used

- **HTML5**  
- **CSS3**  
- **JavaScript** (for animations, cursor, preloader, etc.)  

---

## 📂 Project Structure

```
portfolio-website/
│── index.html        # The main HTML file
│── style.css         # Styling (if separated out)
│── script.js         # JavaScript for animations and interactivity
│── assets/           # Images, icons, resume PDF, etc.
│── README.md         # This documentation
```

## ⚡ Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/portfolio-website.git
   ```

2. Open the folder and double-click `index.html` in your browser to view.

> 💡 Tip: If using **VS Code**, you can install the *Live Server* extension for live reloading while editing.

### Deploy Online

You can host this site for free using:

- **GitHub Pages**  
- **Netlify**  
- **Vercel**
